# Maximaster Practice 2

Веб-приложение каталога товаров, включающее клиентскую витрину, серверный API и административный интерфейс для управления товарными данными.

## Описание

Проект реализован по архитектуре `frontend + backend` и предназначен для отображения каталога товаров и детальных карточек с характеристиками и изображениями.

Клиентская часть (`frontend`) построена на React и Vite. Приложение содержит страницу каталога и страницу отдельного товара. Данные загружаются с backend по HTTP-запросам.

Серверная часть (`backend`) построена на Django и Django REST Framework. На backend реализованы:
- модели товаров, изображений и характеристик;
- API для списка товаров и детальной карточки;
- административный интерфейс для редактирования данных;
- раздача медиафайлов в режиме разработки.

Взаимодействие компонентов:
- список товаров: `GET /api/products/`;
- детальная карточка: `GET /api/products/{id}/`;
- изображения и медиафайлы: `/media/...`.

## Функциональные возможности

- отображение каталога товаров с загрузкой данных из API;
- сортировка каталога по цене и по алфавиту;
- переход на страницу детальной карточки товара;
- отображение описания, цены, статуса наличия, артикула, бренда и характеристик;
- отображение превью и галереи изображений товара;
- административное управление товарами, изображениями и характеристиками через Django Admin.

## Установка и запуск на новом ПК

### Предварительные требования

- Python 3.11 или выше (совместимая версия для Django 6)
- Node.js и npm
- Git

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd maximaster-practice-2
```

### 2. Установка и запуск backend

Перейдите в директорию backend:

```bash
cd backend
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости backend (минимально необходимые по коду проекта):

```bash
pip install Django djangorestframework Pillow
```

Примените миграции:

```bash
python manage.py migrate
```

Запустите backend:

```bash
python manage.py runserver
```

Backend будет доступен по адресу: `http://127.0.0.1:8000/`.

### 3. Установка и запуск frontend

Откройте второй терминал и перейдите в директорию frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm ci
```

Запустите frontend в режиме разработки:

```bash
npm run dev
```

Frontend будет доступен по адресу, указанному Vite (обычно `http://127.0.0.1:5173/`).

### 4. Проверка работоспособности

Проверьте следующие URL:

- frontend: `http://127.0.0.1:5173/`
- backend: `http://127.0.0.1:8000/`
- API товаров: `http://127.0.0.1:8000/api/products/`
- административная панель: `http://127.0.0.1:8000/admin/`

Примечание: файл `backend/db.sqlite3` не хранится в Git (игнорируется `.gitignore`). На новом окружении после `migrate` база будет пустой, поэтому данные необходимо добавить через административную панель.

## Тестовые данные для административной панели

Для ускоренного заполнения каталога используйте подготовленные тестовые материалы:

- Файл с тестовыми данными расположен по пути `docs\test-products.txt`.
- Файл содержит тестовые продукты с номерами 2, 3, 4 и 5.
- Тестовые изображения расположены по пути `frontend\src\assets\images\pictures`.
- Имена изображений соответствуют номерам продуктов из файла `docs\test-products.txt`.
- Для продукта №2 используются изображения вида `product2-0`, `product2-1` и далее.
- Для продукта №3 используются изображения вида `product3-0`, `product3-1` и далее.
- Аналогичная схема именования применяется для продуктов №4 и №5.

## Дополнительная информация

- Основная конфигурация backend: `backend/config/settings.py`.
- Маршрутизация backend и API: `backend/config/urls.py`, `backend/products/urls.py`.

- Статические изображения frontend: `frontend/src/assets/images`.

Отдельное замечание по административному доступу: в текущей реализации (`backend/config/admin.py`) административный интерфейс доступен по адресу `/admin/` без стандартной аутентификации Django.
